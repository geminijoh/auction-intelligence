# 📑 부동산 인텔리전스 플랫폼 화면 기획 & 기능 정의서 (PRD)

> **프로젝트명**: PropIntelligence (개인 실전 투자 & 자산 분석 자체 플랫폼)  
> **버전**: v1.0.0  
> **작성일자**: 2026-11-20  
> **대상 환경**: React (Next.js / Vite) + TypeScript + Tailwind CSS + Node.js  
> **접근 제어**: 1인 개인 사용 목적의 자체 단순 PIN 비밀번호 보안  

---

## 1. 프로젝트 개요 및 기획 배경

본 플랫폼은 기존에 개별적으로 구축된 **부동산 투자 계산기, 경매 분석 시뮬레이터, 리츠/배당 퀀트 비교 시스템, 시장 동향 리포트** 등의 자산을 단일 웹 플랫폼으로 통합 구현하여, 언제 어디서든 실전 투자 의사결정을 빠르고 정밀하게 내릴 수 있도록 지원하는 **개인 전용 실전 투자 인텔리전스 시스템**입니다.

### 1.1 핵심 가치 및 목표
1. **실전 중심 UI**: 복잡한 부동산 계산(취득세, 중개보수, 채권할인, 레버리지 ROE)을 실시간 슬라이더와 퀵 버튼으로 1초 만에 확인.
2. **경매 시뮬레이션 연동**: 입찰가 변경 시 안전마진, 실투자금, 보고서 브리핑이 실시간으로 상호 동기화되는 인터랙티브 뷰.
3. **가벼운 개인 보안**: 번거로운 소셜 로그인 없이 4~6자리 PIN 번호로 빠르게 접근 및 개인 계산 히스토리 보관.
4. **모듈형 확장성**: React + TypeScript 기반의 읽기 쉽고 엄격한 타입 정의로 유지보수 및 추후 확장 용이.

#### 1.3 핵심 계산 공식 및 비즈니스 로직
1. **취득세 및 부가세 산출**:
   - 주택 1주택/비조정 2주택:
     - 6억 이하: $1.0\%$
     - 6억 초과 ~ 9억 이하: $\text{세율}(\%) = \left(\frac{\text{매매가(억원)} \times 2}{3} - 3\right)$
     - 9억 초과: $3.0\%$
     - 지방교육세: 취득세액의 $10\%$ (또는 중과 구간 $0.4\%$)
     - 농어촌특별세: 전용 85㎡ 초과 시 $0.2\%$ (다주택 중과 시 $0.6\% \sim 1.0\%$)
   - 오피스텔 / 상가: 취득세 $4.0\%$, 교육세 $0.4\%$, 농특세 $0.2\%$ (합계 $4.6\%$)
2. **법정 중개보수 상한요율 산출**:
   - 주택 5천만 미만: $0.6\%$ (한도 25만), 2억 미만: $0.5\%$ (한도 80만), 9억 미만: $0.4\%$, 12억 미만: $0.5\%$, 15억 미만: $0.6\%$, 15억 이상: $0.7\%$
   - 오피스텔: $0.5\%$, 상가/토지: $0.9\%$
3. **국민주택채권 할인액 추정**:
   - $\text{채권할인액} = (\text{매매가} \times 0.72[\text{공시지가율}]) \times 0.026[\text{매입률}] \times \text{할인율}(\%)$
4. **투자 수익성 지표**:
   - $\text{총 소요비용} = \text{매매가} + \text{총 부대비용(취득세+중개료+채권/법무비)}$
   - $\text{실투자금(순자본 Equity)} = \text{총 소요비용} - \text{대출금} - \text{임대보증금}$
   - $\text{연 순현금흐름} = (\text{월세} \times 12) - (\text{대출금} \times \text{대출금리})$
   - $\text{자기자본수익률(ROE)} = \frac{\text{연 순현금흐름}}{\text{실투자금}} \times 100$
   - $\text{총투자수익률(Cap Rate)} = \frac{\text{연간 임대료}}{\text{매매가}} \times 100$
5. **레버리지 지렛대 판정**:
   - $\text{Cap Rate} > \text{대출금리} \rightarrow$ **[양(+)의 레버리지: 대출을 활용할수록 자기자본수익률 증가]**
   - $\text{Cap Rate} < \text{대출금리} \rightarrow$ **[역(-)의 레버리지: 이자 비용이 월세를 초과하여 수익률 훼손 경고 뱃지 출력]**

#### 2.2 핵심 기능 및 계산 로직
1. **입찰가 실시간 분석**:
   - $\text{낙찰가율} = \frac{\text{희망입찰가}}{\text{감정가}} \times 100$
   - $\text{급매 시세 대비 안전마진} = \text{급매시세} - \text{희망입찰가}$ (할인율 $\%$ 표시)
2. **실제 현금 소요액(Cash Requirement)**:
   - $\text{입찰보증금} = \text{최저입찰가의 } 10\%$ (법원 납부 필수 금액)
   - $\text{경락대출 가능액} = \min(\text{낙찰가} \times \text{LTV}, \text{감정가} \times \text{감정가대비 LTV})$
   - $\text{잔금 실납부액} = \text{낙찰가} - \text{입찰보증금} - \text{경락대출금}$
   - $\text{총 필요현금} = \text{입찰보증금} + \text{잔금 실납부액} + \text{취득비용} + \text{명도/수리비}$
3. **출구 전략별 시뮬레이션**:
   - **전세 전환형**: 전세금 수령 시 $\text{회수 순자본} = \text{전세보증금} - \text{대출상환액}$. 실투자금 $\le 0$ 일 경우 "무피/플피 투자 달성" 뱃지 표시.
   - **월세 전환형**: 월 순수익, 연간 Cash-on-Cash ROE 산출.
   - **단기 매도형**: 단기양도세율(또는 필요경비 차감 후) 세전/세후 순차익 시뮬레이션.
4. **동적 연동 보고서 생성**:
