# [PRD] 로컬 실행형 부동산 경매 매물 분석 및 브리핑 웹앱

## 1. 프로젝트 개요 및 육하원칙 (5W1H)
본 프로젝트는 복잡한 서버나 설치 과정 없이, 내 PC의 로컬 폴더에 저장된 단일 HTML 파일을 브라우저로 열어 부동산 경매 물건의 핵심 투자 지표를 기록하고, 고객 상담 시 즉각적으로 시각화된 브리핑 자료로 활용하기 위해 기획되었습니다.

*   **Who (누가):** 부동산 경매 컨설턴트(나)와 경매 투자 상담을 받는 예비 매수자(고객)
*   **When (언제):** 경매 물건 사전 권리·수익성 분석 시, 그리고 고객과 대면/비대면으로 물건 브리핑을 진행할 때
*   **Where (어디서):** 별도의 인터넷 서버 구축 없이, 내 PC(노트북 등) 로컬 폴더 내 웹 브라우저 환경에서 즉시 실행
*   **What (무엇을):** 해당 경매 물건의 기본 정보, **주변 개발 호재, 취득세 등 세금 추산, 갭투자(실투자금) 분석, 예상 월세 수익률, 경락잔금대출 한도 및 이자 계산** 등 핵심 투자 데이터
*   **How (어떻게):** 물건의 수치 데이터를 입력·저장하고, 브리핑 모드(상세 보기)에서 고객에게 직관적인 대시보드 형태의 요약 카드와 수익률 계산 결과를 보여주며 설명
*   **Why (왜):** 물건별 분석 히스토리를 체계적으로 기록·유지하고, 상담 시 엑셀이나 수기 메모 대신 전문적이고 신뢰감 있는 시각 자료를 제시하여 고객의 의사결정을 돕기 위함

## 2. 기술 스택 및 아키텍처 제약사항 (비개발자 맞춤형)
*   **단일 파일 구조 (Single File):** `index.html` 파일 하나에 HTML, CSS, JavaScript 코드를 모두 통합합니다. (별도 빌드 과정, Node.js, React 등 프레임워크 절대 배제)
*   **스타일링:** **Tailwind CSS (CDN 방식)**를 `<head>`에 삽입하여 빠르고 현대적인 UI를 구현하며, 필요시 커스텀 `<style>` 태그를 활용합니다.
*   **데이터 저장소:** 브라우저 내장 저장소인 **`localStorage`**를 활용하여 별도 DB 없이도 브라우저를 껐다 켜도 데이터가 유지되도록 설계합니다. (백업용 JSON 내보내기/불러오기 기능 포함 권장)
*   **실행 방식:** 폴더 내 `index.html` 파일을 더블클릭하면 크롬(Chrome)이나 엣지(Edge) 브라우저에서 즉시 실행됩니다.

## 3. UI/UX 화면 설계 명세 (Stitch AI & 오마이디자인 연동용)
> **디자인 툴 활용 가이드:** 아래 명세를 복사하여 **Google Stitch AI**에 입력해 기본 와이어프레임과 레이아웃 시안을 생성한 뒤, **오마이디자인(OhMyDesign)**에서 컬러 팔레트(신뢰감을 주는 네이비/슬레이트 톤 + 강조색 골드/블루), 여백, 폰트 스타일을 다듬어 최종 HTML/Tailwind 코드를 추출하세요.

### [화면 1] 메인 대시보드 및 매물 목록 (목록/검색 뷰)
*   **상단 헤더 (Header):**
    *   좌측: 서비스 로고 및 타이틀 (예: `AUCTION BRIEF | 경매 매물 브리핑 보드`)
    *   우측: `[+ 새 경매 물건 등록]` 버튼 (메인 강조 컬러), `[데이터 백업/복원]` 아이콘 버튼
*   **검색 및 필터 바 (Search & Filter Bar):**
    *   텍스트 검색창: 사건번호, 물건명(아파트/상가명), 지역명으로 실시간 검색
    *   물건 유형 필터 탭: `[전체]`, `[아파트/주거]`, `[상가/업무]`, `[토지/기타]`
*   **매물 카드 그리드 (Card Grid - 3열 배치):**
    *   각 카드 구성요소: 사건번호 뱃지, 물건명 및 소재지, 감정가 vs 최저가(유찰 횟수), **핵심 요약 뱃지(예상 수익률 %, 실투자금)**, `[브리핑 보기]` 버튼, `[수정]`/`[삭제]` 아이콘

### [화면 2] 매물 상세 브리핑 뷰 (고객 설명용 프레젠테이션 모드)
*   **상단 컨트롤 바:** `[← 목록으로 돌아가기]` 버튼, `[브리핑 모드 전환(입력폼 숨김/전체화면)]` 토글 스위치, `[인쇄 / PDF 저장]` 버튼
*   **섹션 A: 물건 개요 및 개발 호재 요약 (좌측 상단)**
    *   사건번호, 매각기일, 소재지, 면적(전용/대지), 감정가, 최저입찰가, 입찰목표가
    *   **개발 정보 하이라이트 박스:** 교통 호재, 재개발/재건축, 인근 배후수요 등 핵심 포인트를 불릿(Bullet) 형태로 깔끔하게 강조 표시
*   **섹션 B: 핵심 재무·투자 시뮬레이션 카드 (우측 상단 - 4분할 강조 카드)**
    *   카드 1 (**대출 분석**): 예상 낙찰가 대비 대출 한도(LTV %), 예상 대출금액, 월 예상 이자
    *   카드 2 (**세금 및 부대비용**): 취득세율(%), 예상 취득세, 법무비/명도비 등 합계
    *   카드 3 (**갭투자 분석**): 예상 전세가, **필요 실투자금(낙찰가+부대비용-대출-보증금)** 강조 표시
    *   카드 4 (**월세 수익률**): 보증금 / 월세, **연 순수익률(ROI %)** 및 대출 이자 차감 후 순월수익 강조 표시
*   **섹션 C: 상세 브리핑 메모 (하단 전체)**
    *   권리분석 특이사항, 임차인 현황, 현장 임장 체크포인트 요약 텍스트

### [화면 3] 매물 등록 및 수정 모달/패널 (데이터 입력 폼)
*   직관적인 4단계 탭 또는 섹션으로 구분된 입력 폼:
    1.  **기본 정보:** 사건번호, 물건유형, 물건명, 주소, 감정가, 최저가, 목표낙찰가
    2.  **개발/권리 정보:** 개발 호재 요약(텍스트 에리어), 특이사항 메모
    3.  **대출/세금 설정:** 예상 대출금(또는 비율 입력 시 자동계산), 대출 금리(%), 취득세율(%), 기타 부대비용(명도비 등)
    4.  **임대/수익 설정:** 예상 전세가(갭투자용), 예상 월세 보증금 및 월세(수익형용)
*   하단 고정 버튼: `[취소]`, `[저장하기]` (입력값 기반 수익률·실투자금 자동 계산 후 저장)

## 4. Gemini CLI 실행용 3단계 분할 프롬프트

터미널에서 Gemini CLI를 실행한 뒤, 아래 프롬프트를 **1단계부터 3단계까지 순서대로 복사해서 입력**하세요. (1단계 실행 전, Stitch와 오마이디자인으로 뽑은 HTML/CSS 시안 코드를 준비해 두시면 더욱 좋습니다.)

### [1단계] UI 시안 반영 핵심 화면 및 기본 동작 구현
```text
나는 비개발자이고, 로컬 폴더에서 더블클릭만으로 실행되는 단일 파일(index.html) 형태의 '부동산 경매 매물 분석 및 브리핑 웹앱'을 만들려고 해.

[기술 제약사항]
- React, Vue 등 프레임워크 절대 사용 금지.
- 순수 HTML, Vanilla JavaScript, 그리고 Tailwind CSS CDN만 사용해서 'index.html' 파일 하나에 모든 코드를 작성해 줘.

[1단계 작업 지시]
첨부(또는 아래 제공)하는 UI 디자인 시안의 레이아웃과 스타일을 바탕으로 핵심 화면 3가지(1. 매물 목록 대시보드, 2. 고객 설명용 상세 브리핑 뷰, 3. 매물 등록 모달창)의 뼈대와 기본 동작을 구현해 줘.
1. 상단 헤더에 타이틀과 [+ 새 매물 등록] 버튼을 배치해 줘.
2. 새 매물 등록 모달에서 [기본정보(사건번호, 물건명, 감정가, 최저가, 목표낙찰가), 개발정보(호재 요약), 대출/세금(대출금, 금리, 취득세, 부대비용), 임대수익(예상전세가, 보증금, 월세)]를 입력할 수 있게 해 줘.
3. 입력한 금액을 바탕으로 자바스크립트가 자동으로 [필요 실투자금(갭투자)], [월 대출이자], [순월수익], [연 수익률(%)]을 계산해서 화면에 표시하도록 만들어 줘.
4. 상세 브리핑 뷰에서는 고객에게 화면을 보여주며 설명하기 좋도록 입력창은 숨기고, 핵심 수치 카드와 개발 호재가 크고 깔끔하게 보이도록 '브리핑 모드' UI를 적용해 줘. (초기 테스트용 샘플 경매 매물 데이터 2개를 기본으로 넣어줘.)

[여기에 Stitch AI / 오마이디자인에서 추출한 HTML/CSS 코드가 있다면 붙여넣기]
```

### [2단계] 브라우저 로컬 저장(localStorage) 및 데이터 백업 기능 추가
```text
방금 만든 index.html 파일에 데이터를 영구적으로 보관할 수 있는 기능을 추가해 줘.

[2단계 작업 지시]
1. 브라우저의 `localStorage`를 연동해서, 내가 새로 등록한 경매 매물 데이터가 브라우저를 껐다 켜거나 새로고침해도 사라지지 않고 그대로 유지되게 해 줘. (단, 처음 실행해서 저장된 데이터가 아예 없을 때만 초기 샘플 데이터 2개를 보여줘.)
2. 로컬 환경(파일 이동이나 브라우저 캐시 삭제 등)에 대비할 수 있도록 상단 헤더에 [데이터 백업(JSON 다운로드)] 버튼과 [데이터 복원(JSON 불러오기)] 버튼을 추가하고 기능을 구현해 줘.
3. 금액을 입력할 때(예: 350000000) 숫자가 헷갈리지 않도록 입력창 옆이나 아래에 한글 단위(예: '3억 5,000만 원')가 실시간으로 표시되는 편의 기능을 넣어줘.
```

### [3단계] 검색·수정·삭제 및 브리핑 인터랙션 마감
```text
이제 실무에서 고객과 상담할 때 완벽하게 쓸 수 있도록 index.html의 나머지 기능과 디테일을 마감해 줘.

[3단계 작업 지시]
1. 메인 대시보드 상단에 검색창과 물건 유형 필터(전체, 아파트/주거, 상가/업무, 토지/기타)를 만들어서, 사건번호나 물건명, 지역명을 입력하면 실시간으로 매물 카드가 필터링되게 해 줘.
2. 각 매물 카드와 상세 브리핑 화면에서 기존 등록된 내용을 불러와 고칠 수 있는 [수정] 기능과, 확인 팝업 후 지울 수 있는 [삭제] 기능을 완성해 줘.
3. 고객 브리핑 화면에서 실시간으로 '목표 낙찰가'나 '예상 월세', '대출 금리'를 슬라이더나 간단한 +/- 버튼으로 미세 조정하면서 고객과 함께 수익률 변화를 즉석에서 시뮬레이션해 볼 수 있는 [즉석 수익률 시뮬레이터] 영역을 상세 뷰 하단에 추가해 줘. (시뮬레이션 값은 원본 저장 데이터를 덮어쓰지 않고 화면에서만 테스트할 수 있게 해 줘.)
4. 상세 브리핑 화면 우측 상단에 [인쇄 / PDF 저장] 버튼을 만들고, 인쇄 시 불필요한 버튼들은 숨겨지고 브리핑 카드만 깔끔하게 A4 용지에 출력되도록 `@media print` CSS를 적용해 줘.
```
